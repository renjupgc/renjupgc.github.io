GitHub 凭证

数据工作流

触发后等待 GitHub Actions 跑完，通常几十秒到几分钟。

snapshot-visits.yml
把访问埋点从 ntfy 通道归档进 data/visits.ndjson，并补查 IP 归属地。统计页的数据靠它更新。
update-duiju.yml
重出对局接口与积分榜。改赛果请用「赛果录入」页，那里可以带参数提交；这里只做无参刷新。
